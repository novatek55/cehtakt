# Цехтакт для своего сервера

Версия 0.1.1. В этой сборке доступны справочники, техкарты, заказы,
производственные задания, склад, закупки и отчёты. База при установке пустая.
В пакет входят код сервера на Python, готовая сборка интерфейса
и тексты лицензий сторонних компонентов в каталоге `third-party`.

- [Скачать для своего сервера](https://github.com/novatek55/cehtakt/releases/latest)
- [Попробовать в браузере](https://demo.newtekpro.ru/)
- [Исходники сервера](backend/)
- [Поддержка в Telegram @ProMelnik](https://t.me/ProMelnik)

Исходный код сервера и файлы установки доступны в репозитории. Интерфейс
поставляется в виде готовой сборки в каталоге `frontend`.

## Установка на Linux

Понадобятся Docker Engine с Docker Compose, `openssl`, `unzip` и доступ
к Docker Hub и PyPI на время сборки. Скачайте архив, распакуйте его и запустите
в каталоге `cehtakt`:

```sh
sh install.sh
```

При первом запуске скрипт создаст секреты, подготовит базу и предложит задать
логин и пароль администратора. Откройте `http://localhost:8080/` и войдите
под этим пользователем.

Если Docker работает на удалённом сервере, откройте туннель со своего компьютера.
Подставьте адрес сервера и имя своего пользователя:

```sh
ssh -N -L 8080:127.0.0.1:8080 пользователь@сервер
```

Оставьте туннель открытым и зайдите на `http://localhost:8080/` в браузере.
Если порт на сервере занят, измените `CEHTAKT_PORT` в файле `.env` в каталоге
установки и повторите запуск. В команде туннеля укажите выбранный порт после
`127.0.0.1:`.

## Начало работы

1. В настройках задайте название компании и создайте участки. Назначьте
   исполнителей и проверьте их права.
2. Добавьте материалы и изделия в каталог. Укажите состав и операции в техкартах.
3. Задайте начальные остатки материалов. Создайте заказ и запустите выпуск.

В этой версии поддерживается доступ через локальный адрес или SSH-туннель.
Интеграции с маркетплейсами, чат, учёт времени, распознавание документов
и загрузка вложений в техкарты в установку не входят.

## Обновление с 0.1.0

Распакуйте новый архив поверх текущего каталога `cehtakt` и снова выполните
`sh install.sh`. Сохраните свой файл `.env` и том с базой.

## Данные и обслуживание

Заказы, техкарты и остатки хранятся в томе Docker `cehtakt_database`.
Команда `docker compose down` остановит приложение с сохранением базы.
Для запуска используйте `docker compose up -d`. Команда
`docker compose down -v` удаляет данные.

Храните резервную копию базы и файла `.env` перед обновлением. Файл `.env`
содержит секреты установки. Храните его на своём сервере и сохраните при
переустановке поверх существующей базы.
