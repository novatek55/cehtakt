# Цехтакт

Система управления производством для небольших цехов. Техкарты, заказы, производственные задания, склад, закупки и отчёты.

- [Скачать для своего сервера](https://github.com/novatek55/cehtakt/releases/latest)
- [Попробовать в браузере](https://demo.newtekpro.ru/)

Релиз содержит пакет для Linux с Docker Compose, готовым интерфейсом и инструкцией на русском.
